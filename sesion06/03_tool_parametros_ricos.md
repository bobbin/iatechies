# Ejercicio 3: Tool con parámetros más ricos

## Objetivo
Aprender a crear tools con parámetros avanzados: enums, parámetros opcionales y descripciones detalladas.

## Conceptos Clave
- **enums**: Ayudan al modelo a no inventarse valores, limitando las opciones válidas.
- **parámetros opcionales**: Evitan obligar al usuario a especificar todo siempre.
- **required**: Define qué parámetros son obligatorios en la llamada.
- **Validación**: El modelo solo puede usar valores válidos según el schema.

## Qué vamos a hacer
1. Crear una tool con enums para limitar valores válidos.
2. Incluir parámetros opcionales.
3. Mostrar cómo el modelo usa correctamente los valores permitidos.
4. Ejecutar la función y mostrar el resultado estructurado.

## Instrucciones
Ejecuta el script:
```bash
python 03_tool_parametros_ricos.py
```

**Nota**: Requiere `OPENAI_API_KEY`. Este ejercicio muestra cómo definir tools más robustas y controladas.
