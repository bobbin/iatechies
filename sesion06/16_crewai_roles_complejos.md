# Ejercicio 16: Roles complejos en CrewAI

## Objetivo
Aprender a crear agentes con roles más complejos, personalidades definidas y habilidades específicas en CrewAI.

## Conceptos Clave (Slides C1-C3)
- **Roles complejos**: Los agentes pueden tener personalidades detalladas (backstory).
- **Habilidades específicas**: Cada rol tiene habilidades y experiencia definidas.
- **Tareas con contexto**: Las tareas pueden depender de resultados previos.
- **Flujo secuencial**: Los agentes trabajan en orden definido.

## Qué vamos a hacer
1. Crear 4 agentes con roles complejos:
   - Investigador con experiencia técnica
   - Analista estratégico de negocios
   - Redactor técnico
   - Revisor de calidad
2. Definir tareas con dependencias y contexto.
3. Ejecutar un flujo completo de trabajo en equipo.
4. Mostrar cómo cada agente aporta desde su especialidad.

## Instrucciones
Ejecuta el script:
```bash
python 16_crewai_roles_complejos.py
```

**Nota**: Requiere `OPENAI_API_KEY`. Este ejercicio muestra cómo crear equipos de agentes con roles bien definidos.
