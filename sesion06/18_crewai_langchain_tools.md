# Ejercicio 18: Integración CrewAI + LangChain Tools

## Objetivo
Aprender a usar tools de LangChain dentro de agentes de CrewAI, combinando lo mejor de ambos frameworks.

## Conceptos Clave (Slides C6)
- **Integración**: CrewAI y LangChain se complementan perfectamente.
- **Tools de LangChain**: Pueden usarse directamente en agentes de CrewAI.
- **Sinergia**: CrewAI para orquestación, LangChain para tools y pipelines.

## Qué vamos a hacer
1. Crear tools de LangChain para análisis de datos CSV.
2. Asignar estas tools a un agente de CrewAI.
3. Crear un equipo donde algunos agentes usan tools y otros no.
4. Demostrar la integración perfecta entre ambos frameworks.

## Instrucciones
Ejecuta el script:
```bash
python 18_crewai_langchain_tools.py
```

**Nota**: Requiere `OPENAI_API_KEY` y pandas. Este ejercicio muestra la integración recomendada entre CrewAI y LangChain.
