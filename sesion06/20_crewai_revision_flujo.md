# Ejercicio 20: Flujo con revisión e iteración en CrewAI

## Objetivo
Aprender a crear un flujo donde un revisor puede solicitar mejoras y el proceso se repite hasta alcanzar la calidad deseada.

## Conceptos Clave (Slides C4, C7)
- **Revisión iterativa**: El contenido puede mejorarse basándose en feedback.
- **Criterios de calidad**: El revisor evalúa según estándares definidos.
- **Flujo de mejora**: El escritor incorpora sugerencias del revisor.

## Qué vamos a hacer
1. Crear un escritor y un revisor.
2. Definir un flujo: escritura → revisión → mejora.
3. Mostrar cómo el revisor puede solicitar mejoras.
4. Demostrar el proceso iterativo de calidad.

## Instrucciones
Ejecuta el script:
```bash
python 20_crewai_revision_flujo.py
```

**Nota**: Requiere `OPENAI_API_KEY`. Este ejercicio muestra cómo implementar un proceso de revisión iterativo.
