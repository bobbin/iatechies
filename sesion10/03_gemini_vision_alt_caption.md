# Ejercicio 03 — Gemini Vision: alt-text + pie de foto (JSON)

## Objetivo

Generar dos piezas editoriales a partir de una imagen:

- `alt_text`: accesible, máximo 120 caracteres
- `pie_foto`: informativo, máximo 180 caracteres

Ambas en **JSON**.

## Ejecutar

```bash
python sesion10/03_gemini_vision_alt_caption.py sesion10/inputs/ejemplo.jpg
```

## Notas

- Requiere `GOOGLE_API_KEY` y opcionalmente `DEFAULT_MODEL_GOOGLE` en `sesion10/.env`.
