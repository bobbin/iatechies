# Ejercicio 07 — PDF: extraer datos de una factura (Gemini)

## Objetivo

Tomar un **PDF** con texto (no escaneado) y devolver un **JSON estructurado** de factura usando **Gemini**.

## Ejecutar

```bash
python sesion10/07_gemini_pdf_factura_extract.py sesion10/inputs/factura.pdf
```

Modo demo (sin argumentos): intenta `sesion10/inputs/factura.pdf`.

## Importante (PDF escaneados)

Si es un PDF escaneado (solo imágenes), necesitarás OCR (convertir páginas a imágenes y usar multimodal). Si quieres, lo añadimos como ejercicio 08.
